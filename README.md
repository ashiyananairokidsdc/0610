# 在庫管理（歯科医院向け）

React + Vite 製の在庫管理アプリです。データは Firebase（Firestore）に保存され、
別の端末で開いても自動で同じ内容に同期されます。Firebase の設定はすでにコードに
組み込み済みなので、GitHub にアップロードして Vercel でデプロイするだけで動きます。

## デプロイ手順（かんたん）

1. このフォルダの中身を GitHub のリポジトリにアップロードする。
2. Vercel でそのリポジトリを Import する（Framework は自動で Vite と判定。設定の変更不要）。
3. Deploy を押す。発行された URL をどの端末で開いても同じ在庫データが見えます。

※ 事前に Firebase 側で「Firestore Database を作成」し、「ルール」を
`allow read, write: if true` にして公開しておいてください。

## 手元で動かす場合（任意）

```bash
npm install
npm run dev
```

## 使い方

- 右上「商品を追加」で登録（項目／コード／在庫数／発注ライン／単価／保管場所／発注先／備考／画像）。
- 価格は「箱単位（1箱価格＋入数で単価を自動計算）」と「1個単位（単価を直接入力）」を切替可。
- 在庫が発注ライン以下になると「要発注」と表示。上部のクリップボードアイコンが発注リスト（発注先ごと）。
- 歯車アイコンで項目・保管場所・発注先のマスタを編集。変更は自動でクラウド保存されます。
